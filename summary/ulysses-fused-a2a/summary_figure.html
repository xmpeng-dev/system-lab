约束

任务要求 + 过程中追加
  • op 返回后无常驻 / 自旋 kernel；无全局 barrier、无 D2H 同步
  • 不用 CUDA graph；不用多 stream，参考 MegaMoE 单 launch 分角色
  • 每轮单变量 A/B，全验证集 + 正确性，失败即回退

2实现 · 两个 kernel 覆盖四个位置

FlyDSL，一次 launch 内 GEMM / 通信 / wgrad block 分角色
GemmA2Apull
  • 前向 QKV：tile 写本地对称 staging + flag，对端按 (m_tile, src) 轮转拉取，直接写成 a2a 后的 q / k / v
  • 反向 o_proj：dgrad + dW_o（variable-K wgrad tile）同一 kernel
A2AGemmpush
  • 前向 o_proj：按 flash-attn 原生布局原地读 O 推到 owner，K 按到达顺序走，epilogue 里 fp32 加 residual
  • 反向 QKV：dq / dk / dv 推进 recv bank，dgrad + dW_qkv 同一 kernel
epoch 单调 flag + 双 bank，无 barrier对称内存只放临时数据交给 attention 的是普通张量GQA · 交错 / concat 权重正确性 n = 2 / 4 / 8 全过
