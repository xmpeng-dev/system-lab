# A：Region 准入取决于 compiler 是否独立操作它

## 我是谁

我是 GPT-5.6 Sol，本轮作为 A，综合上一 cycle 并提出 RegionGraph 的机械边界。

## 我回应的命题

> 什么条件允许新增 semantic region，并如何阻止 `LinearRegion`、`ReshapeRegion`
> 继续增长，最终退化为 primitive MathGraph？

## 发言

建议采用一条必要条件：

> 一个对象只有被 compiler **独立 transform、schedule、verify、measure 或 bind
> implementation**，才有资格成为全局 RegionGraph node。

至少命中以下一项：

1. **语义 lowering 边界**：同一模型语义能 lower 为不同 task topology，例如
   `RoutedExperts`；
2. **effect 边界**：包含 collective、host sync 或跨 step mutable state，需要 verifier
   观察；
3. **调度/资源边界**：需要独立 recompute、residency、F/B/W 拆分或 overlap；
4. **稳定 variant 边界**：存在两个可测实现，共享固定 ports、数值 contract 和
   provenance，例如 fused/unfused `ResidualNorm`；
5. **独立归因边界**：性能判断必须在这里验收，且归并进父 region 会丢失可行动信息。

同时增加两个排除规则：

- 单纯 shape/view/elementwise 不是 region；`Reshape`、`Split`、`Concat`、`Expand`
  留在 region body；
- 单个 kernel 可替换不自动产生 region。`Linear` 的 kernel/tile 可以是父 region 的
  implementation parameter；只有 compiler 必须独立移动其 wgrad、residency 或 effect
  时，才把它 lower 成 Program task。

关键区分是：

```text
Semantic RegionGraph：模型与可搜索决策
Executable Program：region lowering 后的细粒度 tasks
```

Program 可以有多个 GEMM、collective 和 wgrad task，但这不等于 Semantic Graph 必须有
对应 primitive nodes。fine execution task 是“怎么执行”，region 是“什么语义和哪个
决策边界”。

建议的最小 RegionGraph 节点集合：

```text
Embedding/Prolog
Attention
ResidualNorm
Router
RoutedExperts
DenseMLP
Epilog/Loss
```

`RoutedExperts` lowering 后仍可产生 dispatch metadata、A2A、expert GEMM、combine A2A
和 aggregate tasks，现有 `hands_over` 与 verifier 继续读取这些 Program tasks。

## 可验证的防退化规则

新增 region 的 PR 必须回答：

```text
independent_action:
  transform | schedule | verify | measure | bind
lost_if_inlined:
  <具体丢失能力>
current_consumer:
  <已有 pass / verifier / profiler / binding>
```

若 `current_consumer` 只有“未来 search”，拒绝新增。若一个 region 连续两个 milestone
没有独立 consumer，应合并回父 region 或说明保留原因。

## 判断与假设

- **判断**：region 数量应由 compiler 的现有独立消费者决定，而不是模型 primitive
  数量决定。
- **假设**：region lowering 能直接生成 typed Program tasks，保留 fine schedule，
  无需保留同粒度 semantic nodes。
- **证伪点**：若 explicit VJP、FSDP residency 或 deferred wgrad 无法从 region
  contract 生成现有 Program，准入规则不够。
