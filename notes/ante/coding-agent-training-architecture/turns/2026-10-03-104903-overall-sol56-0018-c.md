# C：整体架构最终综合

## 产品边界

Cairn 是面向 gfx950、节点内 MoE、有限 protected regimes 的可验证执行控制面，不是
通用训练框架、自动调优器或全配置性能保证系统。

## 最终架构

1. **RegionGraph → Program**  
   RegionGraph 只表达 coarse region、有限 `RegionEdge` 和白名单 `RegionGroup`；
   Program 承载 F/D/W、collective、saved state、parameter unit 与 gradients。内部 task
   若支持通用代数/autodiff/alias analysis，即退化为 primitive graph。

2. **Compiler → Runtime**  
   Compiler 生成 symbolically complete Plan；setup 生成 `BindingManifest`；Executor
   无策略执行。允许确定性物化与有限、完备的动态 dispatch 表；禁止在线 autotune、
   heuristic fallback 或改变 kernel/layout/precision/schedule/residency。

3. **Schedule policy**  
   Safety 只定义 causality、channel symmetry、deadlock freedom、resource lifetime。
   receive hoist、P2P grouping、prefetch、handoff、lane order 都是显式版本化 policy。

4. **Evidence budget**  
   采用 `structural-only/correctness/protected`、最多 8 个 E2E regimes、pairwise
   set-cover、shape tier 和 `stale/unprotected`。第九项必须由可复现三元缺陷证明。

5. **Agent contract**  
   Agent 每次提交一个基于 immutable plan/source digest 的可逆 Transform；系统返回
   Compile、Verify、Correctness、Measurement、Attribution 和机械 Verdict。

## 30% Go/No-Go

一个 milestone 后，三项 matched trials 的 median Edit-to-Verdict 必须至少降低 30%：

1. 替换 `AttentionRegion` implementation；
2. 改变 `RoutedExperts` lowering/overlap；
3. 修改 schedule/residency policy。

Edit-to-Verdict 扣除集群排队，但包含编辑、失败迭代、编译和 gates；同时报告 edit
sites、agent actions 和 first-pass correctness。

- **Go**：median 改善至少 30%，三任务无显著退化，gradients、verifier fault classes、
  protected throughput/memory 守住，并可删除旧路径。
- **Stop**：收益不足，需要恢复通用 infer/autodiff/rewrite，旧 consumer 无法清零，或
  evidence 成本超过 agent burden 的下降。

## 修正路线

```text
测量现有 schedule 与三任务基线
→ 最小 Policy 显式化
```

双前端最多存在一个 milestone；artifact 只服务 gate/query，不复制运行日志。

- pairwise evidence 漏掉高阶交互；
- Edit-to-Verdict 受 agent 随机性影响。
