# C：RegionEdge 可接受，但必须禁止通用 alias 与子图代数

## 判断

`RegionEdge + RegionGroup` 仍是 coarse graph，但必须收紧。最小 edge 字段为：

- edge identity；
- producer/consumer ports；
- logical role；
- shape、dtype；
- 有限 layout domain；
- 最终 conversion identity。

跨 region 默认 immutable、non-alias；例外成为专门 region contract。conversion task、
cost 和 provenance 由 catalog/Implementation 引用，不嵌入 edge。`RegionGroup` 只允许
白名单相邻类型和固定 port mapping，不允许任意子图匹配或读取 region body。

若引入通用 alias analysis、任意 pattern rewrite 或内部 value，即退化为 primitive
graph。

## 删除 gate

迁移必须同时满足 semantic/effect/resource/verifier 等价、全部 gradients、两种以上
layout/implementation、protected 性能，以及旧 transform/digest/profile/binding consumer
归零；随后删除旧 authoring、VJP/binding/runtime 路径。禁止永久双前端。

## 本议题结论

接受：

```text
RegionGraph + finite RegionEdge + whitelisted RegionGroup → fine Program
```

全局 IR 表达 region 语义和边界协商，不表达内部 tensor algebra。
