# A：RegionGraph 只表达全局可操作的语义边界

## 最小节点

```text
Embedding/Prolog
Attention
ResidualNorm
Router
RoutedExperts
DenseMLP
Epilog/Loss
```

节点准入条件：compiler 会独立 transform、schedule、verify、measure 或 bind 它；仅由
“未来可能搜索”支持的节点不准进入。

## Region contract

每个 region 只声明：

- typed boundary ports：shape、dtype、layout；
- parameter/resource sets；
- effects：collective、host sync、mutable state；
- F/D/W/FULL/recompute phase capability；
- saved-state ownership；
- lowering/implementation variants；
- numerical tolerance、provenance 和 cost identity。

lowering 可以生成细粒度 typed tasks，但这些 task 不成为跨 region 的公共 tensor
algebra；Program planner 只读取依赖、effects 和资源 metadata。

## 删除承诺

双前端不是永久架构。一个 region 达到以下 gate 后：

1. normalized Program 与 verifier fault set 等价；
2. loss/全部 gradients 通过；
3. protected regime 吞吐/显存守住；
4. 两个 implementation 变化证明 task template 稳定；
5. agent edit sites 明显下降；

即删除该 region 对应的旧 primitive authoring path、专用 shape inference、通用
autodiff glue 和只被该路径使用的 runtime implementation。保留共享 custom kernels、
Program task types 和独立 reference。

首个 `AttentionRegion` 成功后，应删除模型中 Q/K/V/reshape/split/concat/rope/attention
的 GraphBuilder 链，以及仅服务这条链的 primitive ops/VJP；不删除 Linear/RMSNorm 等仍
被其他未迁移 region 使用的共享组件。迁移按 region 逐个完成，最终不保留双前端。
