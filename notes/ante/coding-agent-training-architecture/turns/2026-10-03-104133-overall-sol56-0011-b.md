# B：ExecutablePlan 应符号完备，而非物理完全绑定

## 事实

FSDP unshard 后的 tensor/storage、ProcessGroup/RCCL handle、launcher 决定的 ranks、
动态 expert row count，以及首次 FSDP/RCCL 资源，都无法在离线 compiler 获得。

因此 Plan 应对**选择**完全绑定，对**物化**显式延迟：

- `TopologyRequirement`：arch、mesh、node boundary、queue budget；
- `GroupRef`：逻辑 role、成员 ranks、backend/options；
- `ParamRef`：residency unit、FQN、预期 spec；
- `BufferRef`：dtype/layout 与动态 shape expression；
- `KernelDispatchRef`：family、variant/version、有限 shape-key 表、tuning artifact hash；
- `RuntimeAdapterRef`：FSDP/PyTorch ABI 与 capability；
- `PeerHandshakeTask`：连接建立显式进入 setup plan。

setup 生成 `BindingManifest`，记录 topology fingerprint、group members、adapter version 和
tuning-table hash，并进入 run digest。解析必须确定、唯一、无 benchmark、无 heuristic、
无 silent fallback；不满足则拒绝或重新编译。

Executor 可以解析 handle 与动态值，但不能改变 variant、group membership、buffer
policy、schedule 或 residency。正确名称是：

```text
symbolically complete ExecutablePlan
  → environment-bound plan
  → Executor
```
