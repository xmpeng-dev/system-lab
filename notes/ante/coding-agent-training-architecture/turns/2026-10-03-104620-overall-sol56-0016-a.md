# A：Agent 只提交 Transform，系统返回分层 Verdict

## 统一 action

```text
Candidate {
  base_plan_digest
  transform_id + parameters
  preconditions
  expected_mechanism
  expected_effect
  risk: numerics | memory | performance
  required_gates
}
```

agent 不直接宣称成功，也不在 Runtime 内试探。每次只提交一个可逆 Transform。

## 统一 observation

```text
CompileReport     # policy diff, graph/plan digest, passes, bindings
VerifyReport      # shape/effect/channel/residency/deadlock
CorrectnessReport # reference loss + every gradient
Measurement       # profile, memory, environment, protected coverage
Attribution       # mechanism 是否发生、critical-path 变化
Verdict           # accept | reject | inconclusive
```

任何失败都引用 immutable base candidate；rollback 是选择 parent digest，不是反向编辑
工作区。

## Roadmap

### S0 — 冻结事实基线

- Action：不改架构，只补 normalized Plan snapshot、fault injection 和 protected coverage。
- PASS：当前两个模型/五 scheduler/三 lowering 可重放；artifact 自描述。
- Rollback：当前 task-graph tree。

### S1 — 收敛 compiler/runtime

- Action：引入 executable descriptor、symbolic refs 和 BindingManifest。
- PASS：Runtime 不读 `Implementation`/operator type；性能与 gradients 持平。
- 允许修改：binding/runtime seam；不改 IR。

### S2 — `AttentionRegion` 双前端实验

- Action：Region lowering 直接产 F/D/W task template。
- PASS：verifier/correctness/protected evidence 守住，agent edit sites 下降。
- FAIL：需要恢复通用内部 infer/autodiff/rewrite。
- Rollback：删除实验前端。

### S3 — Region-by-region 迁移

- Action：ResidualNorm、Router、RoutedExperts、DenseMLP、Loss。
- PASS：每完成一个 region 就删除对应旧 authoring/VJP/runtime consumer。
- 禁止永久双前端。

### S4 — Policy 显式化

- Action：把 merge、handoff、P2P、residency/prefetch 参数纳入 CompilePolicy。
- PASS：无 module-level performance constants；每个选择进入 digest。

### S5 — 外部 optimization loop

- Action：Transform catalog、bounded search、append-only evidence。
- PASS：search 不进入 Runtime；每个候选经过同一 gates。
