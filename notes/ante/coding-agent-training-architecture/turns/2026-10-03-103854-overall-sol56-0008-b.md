# B：删除 primitive 前必须保留可协商的 RegionEdge

## 事实

当前 `FuseResidualNorm` 匹配跨 scope 的 `Add → RMSNorm`。若迁移
`AttentionRegion` 后只保留 shape/dtype/layout 输出，compiler 看不到 residual
lineage，也无法判断 fused variant 是否保持第二个 `summed` 输出。

Router/RoutedExperts 间也不只有 shape：token、expert index、top-k weight 的逻辑角色
固定，而 dispatch 后可能是 rank-grouped、expert-sorted 或 peer-padded。若 port layout
只有已确定值，compiler 只能插转换，不能联合选择布局。

## 最小跨 region 表示

每条 `RegionEdge` 至少需要：

- SSA identity、producer/consumers 与 use count；
- logical role；
- shape、dtype；
- 有限 `LayoutVar`：producer 可提供集合、consumer 可接受集合；
- alias/mutation 约束；
- layout conversion 的 task template、cost identity 与 provenance。

允许相邻 `RegionGroup` variant：`Attention + ResidualNorm` 可选 fused/unfused；
`Router + RoutedExperts` 可保持 token-major 或直接生成 dispatch-ready layout。rewrite
只能匹配 region 类型、ports 和 edge constraints，不能读取 region 内 primitive。

这仍是 coarse semantic graph：它表达跨 region 协议，不表达 Q/K/V GEMM、reshape 或
elementwise algebra。

## 删除 gate 修正

删除旧 primitive path 前还必须证明：

1. 跨 scope fusion 都有 region-level 等价项；
2. 两种以上 producer/consumer layout 通过联合选择测试；
3. multi-consumer、alias 和额外 residual consumer 会拒绝非法 fusion；
4. 被删 primitive 的 transform、profile provenance 和 digest consumer 已清零。

`normalized Program 等价`不应要求 task-by-task 相同；应比较 semantic outputs、
effects、resource lifetime、verifier fault classes 与测量结果。
